# Brazil Economy Monitor

Interactive dashboard of Brazilian economic indicators, updated automatically every day via GitHub Actions.

**[Open the dashboard](https://fexndev.github.io/monitor-economia-br/)**

## Indicators

| Group | Available metrics |
|---|---|
| **FX rates** | USD/BRL, EUR/BRL, GBP/BRL, CHF/BRL, CAD/BRL |
| **Selic** (base interest rate) | Target (COPOM), Effective |
| **CDI** (interbank rate) | Daily rate (p.a.), YTD, 12 months |
| **IPCA** (official inflation) | Monthly change, YTD, 12 months |
| **IGP-M** (general price index) | Monthly change, YTD, 12 months |
| **INPC** (consumer price index) | Monthly change, YTD, 12 months |
| **Savings account** (Poupança) | Monthly yield, YTD, 12 months |

All indicators are shown in a single chart with dynamic selection. Monthly data from January 2024.

## Features

- **Interactive chart** with several indicators at once and two axes (R$ and %)
- **Group selector**: turn each indicator's metrics on and off independently
- **Hierarchical axis**: months grouped by year and evenly spaced
- **Data labels** with a highlighted background that adapt to the number of series
- **Light/dark theme** persisted in localStorage
- **KPIs** summarised at the top (US dollar, Selic, IPCA, CDI)
- **Multi-series tooltip** on hover
- **Automatic update** Monday to Friday at 6pm BRT via GitHub Actions

## Data sources

| Source | Indicators |
|---|---|
| [BCB/PTAX](https://olinda.bcb.gov.br/olinda/servico/PTAX/versao/v1/aplicacao#!/recursos) | Currency quotes |
| [BCB/SGS](https://www3.bcb.gov.br/sgspub/) | Selic (series 432, 11), CDI (12, 4391), IPCA (433, 13522), IGP-M (189), INPC (188, 11426), Savings (25) |

BCB = Banco Central do Brasil (Brazil's Central Bank).

## Technologies

- HTML, CSS, JavaScript (no frameworks)
- Chart.js + chartjs-plugin-datalabels + custom plugin for the hierarchical axis
- Python (requests) for data collection
- GitHub Actions (automatic updates)
- GitHub Pages (hosting)

## Run locally

```bash
# 1. Install dependencies and collect data
pip install -r scripts/requirements.txt
cd scripts && python fetch_moedas.py && python fetch_selic.py && python fetch_cdi.py \
  && python fetch_ipca.py && python fetch_igpm.py && python fetch_inpc.py && python fetch_poupanca.py

# 2. Serve locally
cd .. && python -m http.server 8000
# Open: http://localhost:8000
```
